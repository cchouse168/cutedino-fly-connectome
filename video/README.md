# 影片動畫

七幕解說動畫，全長 **3:45**。所有數字取自 [`README.md`](../README.md) 與
[`docs/experiment.md`](../docs/experiment.md)，不是示意值。

```
video/
├── player.html   連續播放器（成品，直接開就能播）
├── build.py      把 scenes/ 的分鏡組裝成 player.html
└── scenes/       七幕分鏡原始檔（Design 畫布匯出的 .dc.html）+ 播放器模板
```

---

## 播放

不需要 build step，任何靜態伺服器都行：

```bash
npx serve -l 4173 .
```

然後開 <http://localhost:4173/video/player.html>。

| 按鍵 | 作用 |
|---|---|
| 空白鍵 | 播放 / 暫停 |
| ← → | 倒退 / 快轉 5 秒 |
| 1 – 7 | 跳到第 N 幕 |
| H | 隱藏 / 顯示控制列（錄影用） |
| C | 字幕開關 |
| F | 全螢幕 |

控制列另有速度（0.25× – 2×）與時間軸拖曳。暫停時畫面會**定格在該幀**，方便逐格檢查。

---

## 錄成影片

1. `F` 全螢幕 → `H` 隱藏控制列 → 畫面就是乾淨的 1280×720（會等比放大到螢幕）
2. 用 OBS / Windows 遊戲列 錄 1920×1080、30 fps
3. 按 `Home` 回到 0:00，空白鍵開播，錄完整段
4. 配旁白：字幕的進出時間就是旁白的節奏，逐句對齊即可

想要更乾淨的素材，可以 `C` 關掉字幕、錄一版無字幕的，字幕交給剪輯軟體上。

## 要改東西

| 想改的 | 改哪裡 |
|---|---|
| 字幕文字或時間 | `player.html` 的 `CUES`，格式 `[起秒, 訖秒, "文字"]` |
| 幕長或幕序 | `player.html` 的 `SCENES`（`start` / `dur`），**同時**改 `build.py` 的建立期 |
| 畫面內容 | 改 `scenes/S0*.dc.html`，再跑 `python video/build.py` 重新組裝 |

`build.py` 做的事：抽出每幕的 1280×720 畫面、丟掉分鏡稿專用的旁白條與時間碼、
把迴圈動畫改成單次播放（`both`，結尾不淡出）、把動畫總長拉到該幕的建立期、
掛上 `--seek` 讓播放器能把任一幕推到任意進度。

分鏡稿（含每幕的旁白全文、節拍表與提醒）在 Design 畫布上，`scenes/` 裡的檔案就是它匯出的原始碼。
