# 果蠅大腦玩 cute-dino

用 MaleCNS v1.0 果蠅連接體中 **80 顆真實神經元、1,296 條實測突觸連接**（26,029 個突觸接觸）
構成一段完全固定、不可訓練的電路，去玩 [cute-dino](https://github.com/cchouse168/cute-dino)。
電路後面只接一個 **269 參數**的讀出網路 —— 那是全系統唯一被訓練的東西。

> Built with [fly-connectome-template](https://github.com/cobanov/fly-connectome-template) by [Mert Cobanov](https://github.com/cobanov).

方法與程式架構改編自 [cobanov/flyjump](https://github.com/cobanov/flyjump)（[Fly Dino](https://flydino.cobanov.dev/)），
依 **Cobanov Template Attribution License 1.0** 使用，授權全文見 [`LICENSE-flyjump.txt`](LICENSE-flyjump.txt)。

**本專案所做的修改**（License §4 要求載明）：

1. 環境由 Chromium 恐龍遊戲換成 cute-dino，並改寫為確定性 headless 模擬器
2. 感官通道由 8 個重新映射為 **13 個**（同一張 80 細胞圖，只改工程化的輸入廣播表）
3. 動作空間由 3 個（RUN/JUMP/DUCK）擴充為 **5 個**（加入 LEFT/RIGHT），讀出網路 16→12→5
4. CEM 的 `trainingCourses` 與 `validationSeeds` 因 cute-dino 分數變異較大而調高

## 結果

100 條從未見過的賽道，每條上限 180 秒。

模型為 400 代 CEM 訓練的第 311 代冠軍（訓練種子 20260917）。**選模型的依據是訓練期的驗證分數，
不是下面這張 held-out 表**，否則等於用測試集挑模型。

| 對照組 | 跑完 | 平均存活 | 中位存活 | 平均分數 |
|---|---:|---:|---:|---:|
| **連接體 + 訓練讀出** | **82/100** | **161.1s** | **180.0s** | **2512** |
| 電路靜默（消融） | 0/100 | 3.5s | 3.5s | 21 |
| 未訓練讀出 | 0/100 | 3.5s | 3.5s | 21 |
| 手寫規則 | 25/100 | 82.4s | 55.1s | 1354 |
| 隨機動作 | 0/100 | 4.1s | 3.5s | 24 |
| 完全不動 | 0/100 | 3.5s | 3.5s | 21 |

把電路活性強制歸零，agent 整場只會重複同一個動作，**3.5 秒**撞上第一個障礙物就結束 ——
和「完全不動」的成績一模一樣（100 條賽道全部都是 3.5 秒，那是這個環境的地板）。
換成未訓練的隨機讀出也是 3.5 秒。
中位存活達到 180 秒上限，代表超過一半的賽道牠都撐到最後。

兩個必須同時講清楚的但書：

- **這張表是右截尾的。** agent 有 82/100、手寫規則有 25/100 撞到 180 秒上限，
  其中 24 條賽道雙方都撞頂而變成平手；上限以上的差異這張表量不出來。
- **82/100 是這個部署模型的成績，不是這個方法的成績。** 換訓練種子會得到 46–87/100。

### 長場表現（600 秒，拿掉 180 秒上限）

180 秒的上限是為了與原作可比，但中位存活已頂到 180 秒，量不出上半部的差異。改測 600 秒：

| 對照組 | 撐過 300s（難度封頂） | 平均存活 | 最高分 |
|---|---:|---:|---:|
| **連接體 + 訓練讀出** | **35/100** | **261.4s** | **9008** |
| 電路靜默（消融） | 0/100 | 3.5s | 21 |
| 手寫規則 | 3/100 | 100.6s | 8047 |

**180 秒的上限把差距壓小了。** 拿同一批長場資料在不同上限人工截尾，用同一個統計量比較：

| 截尾上限 | 平均存活比 | Cohen d | 逐場勝 | 平手 | 撞頂 agent/規則 |
|---:|---:|---:|---:|---:|---:|
| 180s | 1.955× | 1.32 | 69 | **24** | 82/25 |
| 360s | 2.561× | 1.62 | 92 | 0 | 6/0 |
| **480s（無截尾）** | **2.599×** | **1.62** | **92** | **0** | **0/0** |

180 秒時有 24 條是雙方都撞頂的假平手，逐場勝率只算得出 69/100；
480 秒完全沒有截尾，勝率 92/100。鑑別力在 360–480 秒就飽和，再拉長到 600 秒沒有增加。

同一個上限也會放大消融比：180s 是 45.8×，480s 是 74.3×。
**兩個數字都要連上限一起報** —— 只報 74.3× 等於用量尺灌水。
（`node scripts/censoring.mjs` 可重現整張表。）

### Replicate：消融效應不是僥倖

單一次訓練的結果不足採信，所以用三個不同訓練種子重跑整條管線：

| 訓練種子 | 冠軍代 | 驗證分數 | 跑完 | 平均存活 | 消融比 | 勝規則 |
|---:|---:|---:|---:|---:|---:|---:|
| 20260915 | 340 | 2064 | 46/100 | 109.7s | 31.2× | 1.33× |
| 20260916 | 337 | 2905 | 87/100 | 167.9s | 47.7× | 2.04× |
| 20260917 | 311 | 2965 | 82/100 | 161.1s | 45.8× | 1.95× |
| **平均 ± 標準差** | | | **71.7 ± 18.3** | **146.2 ± 25.9s** | **41.6 ± 7.4×** | **1.77 ± 0.31×** |

消融比減一個標準差後仍有 34×，遠高於 2× 的判定門檻 —— **這個效應穩定重現**。

**但訓練種子之間的變異很大**（109.7s–167.9s）。這代表任何「改進」都必須用多個種子驗證，
單跑一次分不出是真的改善還是運氣。

而且三個種子**還是不夠**。用實測的配對差異標準差反推，這個設計的最小可偵測差異是
**50 場（基準 71.7 場的 70%）** —— 意思是效應要大到 70% 才看得見。
報告 §5.3 那兩項超參數對照（p = 0.35、p = 0.24）都落在這個下限之內，
能支持的只有「沒有觀察到改善」，不能支持「證明更差」。
（`node scripts/power.mjs` 可重現；核心的消融主張不受影響：t = 7.8、p = 0.016，顯著。）

驗證分數與 held-out 表現相關，但**不足以挑出榜首**：
驗證分數 2965 的種子 20260917 被選為主模型（82/100），
而驗證分數只有 2905 的種子 20260916 其實是 87/100。
把驗證集從 16 條擴大到 64 或 128 條，這個倒置依然存在
（Spearman ρ 0.886 → 0.943，中段排序修好了，榜首沒有）。
所以「用驗證分數選模型」在這裡是**無偏但不精確**的程序。
（`node scripts/validation-size.mjs` 可重現。）

**該誠實講的地方**：本 agent 比不用任何神經網路的手寫規則好 **1.77 ± 0.31 倍**
（這是 180 秒截尾後的保守值；同一個主模型在無截尾的 480 秒量尺上是 2.60×）。
原作 flyjump 在 Chrome Dino 上能跑完 99/100、平均 179.4 秒；cute-dino 難得多
（正弦擺動的飛行障礙、高速子彈、5 個動作、道具與 HP 系統）。
消融對照證明的是「電路有貢獻」，不是「這個 agent 已經是最強解」。

---|---:|---:|---:|---:|
| **連接體 + 訓練讀出** | **40/100** | **102.0s** | **98.0s** | **1593** |
| 電路靜默（消融） | 0/100 | 2.3s | 2.3s | 13 |
| 未訓練讀出 | 0/100 | 2.7s | 2.7s | 16 |
| 手寫規則 | 25/100 | 82.4s | 55.1s | 1354 |
| 隨機動作 | 0/100 | 4.1s | 3.5s | 24 |
| 完全不動 | 0/100 | 3.5s | 3.5s | 21 |

把電路活性強制歸零，存活時間掉到 **1/45**；把讀出網路換成未訓練的隨機權重，掉到 **1/38**。
也就是說，那 269 個參數不是靠硬記過關的 —— 固定的解剖結構確實在做事。

**該誠實講的地方**：本 agent 只比不用任何神經網路的手寫規則好 **1.24 倍**（102.0s vs 82.4s）。
原作 flyjump 在 Chrome Dino 上能跑完 99/100、平均 179.4 秒，遠勝其規則基線；cute-dino 難得多
（正弦擺動的飛行障礙、高速子彈、5 個動作、道具與 HP 系統）。
消融對照證明的是「電路有貢獻」，不是「這個 agent 已經很強」。

**而且它還沒收斂**：驗證分數在 150 代是 1418、400 代是 2082，全程都還在爬。
代數拉長仍有明顯回報 —— 目前的成績是計算預算的下限，不是這個方法的上限。

| 訓練代數 | 冠軍代 | 驗證分數 | 跑完 | 平均存活 | 中位存活 |
|---:|---:|---:|---:|---:|---:|
| 150 | 134 | 1418 | 29/100 | 91.9s | 72.6s |
| 400 | 382 | 2082 | 40/100 | 102.0s | 98.0s |

150 代那次的完整結果保留在 `models/run-150gen/`。

## 使用

### 介面

| 面板 | 內容 |
|---|---|
| 01 / 遊戲 | cute-dino 即時運算，疊出 agent 當下鎖定的障礙物、子彈、道具 |
| 02 / 鍵盤輸出 | flybody 解剖模型操作鍵盤，兩隻前腳依動作按下對應的鍵 |
| 03 / 決策網路 | 16 顆下行神經元 → 12 個隱藏單元 → 5 個動作分數（層間連線亮度＝權重 × 活性） |
| 04 / 大腦活性 | MaleCNS 胞體圖譜點雲，電路細胞按真實座標發光（可拖曳旋轉、滾輪縮放） |
| 05 / 感官通道 | 13 個工程特徵的即時數值與其對應的細胞型態 |

「02 / 鍵盤輸出」需要 WebGL2；不支援時該面板會顯示提示，其餘功能不受影響。

### 執行

不需要 build step。任何靜態伺服器都能跑：

```bash
npx serve -l 4173 .
```

然後開 <http://localhost:4173>。也可以直接部署到 GitHub Pages。

重現訓練與基準（需要 Node 20+，無外部依賴）：

```bash
node scripts/remap-channels.mjs                          # 產生 13 通道輸入廣播表
node scripts/train.mjs 20260917 400                      # CEM 訓練（12 執行緒約 20 分鐘）
node scripts/benchmark.mjs                               # 100 條 held-out 賽道 + 消融對照
node scripts/benchmark-long.mjs 600                      # 長場基準（測難度封頂後的持續能力）
node scripts/replicates.mjs 400 20260915 20260916 20260917  # 三種子 replicate 驗證
node scripts/analyze-ceiling.mjs 1200 100                # 分數上限與死因分析
node scripts/validation-size.mjs                         # 驗證集大小 vs 選模準確度
node scripts/censoring.mjs                               # 截尾上限 vs 鑑別力
node scripts/power.mjs                                   # 配對檢定與最小可偵測差異
```

驗收測試：

```bash
node scripts/verify-determinism.mjs  # 模擬器可重現性
node scripts/verify-policy.mjs       # 電路、讀出、特徵值域、健全性
```

## 架構

```
遊戲狀態
   │
   ↓  13 個工程特徵（值域 0..1）
32 顆輸入細胞   u = 2·(feature − 0.5)
   │
   │  沿 1,296 條實測突觸連接，同步更新 3 輪
   │  h′ = 0.3·h + 0.7·tanh( u + 1.4·Σ W·h )
   ↓
16 顆下行神經元（DNp01、DNp04、DNp35…）
   │
   │  ← 唯一可訓練的部分：269 個參數
   ↓  16 → 12 (tanh) → 5 → argmax
RUN / JUMP / DUCK / LEFT / RIGHT   @ 30 Hz
```

### 為什麼是 13 通道，不是 16

原本打算把每個 LC 型態的 4 顆細胞拆成 2 組得到 16 通道，但實測發現拆不得：

| 型態 | 最佳 2-2 分組的跨組出邊餘弦相似度 | 判定 |
|---|---:|---|
| LC9 / LC16 / LC21 / LPLC2 | 0.000 – 0.004 | 可拆 → 8 通道 |
| LC15 | 0.534 | 勉強可拆 → 2 通道 |
| LC4 / LC11 / LC17 | 0.940 – 0.988 | **不可拆** → 各留 4 細胞，3 通道 |

LC17 的四顆細胞投射相似度高達 0.988 —— 硬拆成兩個通道，電路根本分不出來，
只是讓兩個特徵變成雙胞胎。所以實際上限是 **8 + 2 + 3 = 13**。
三個不可拆的型態改配給最關鍵的特徵（它們細胞數多、下游影響最強）。
量測與指派邏輯都在 [`scripts/remap-channels.mjs`](scripts/remap-channels.mjs) 裡，可重跑驗證。
